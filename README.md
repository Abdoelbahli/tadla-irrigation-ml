# tadla-irrigation-ml

Monthly NDVI prediction with LightGBM over the irrigated **Tadla plain (Morocco)**, and FAO-56 net irrigation
requirement maps derived from it. Master's thesis (PFE), Faculté des Sciences Béni Mellal —
Abdellah EL BAHLI, supervised by Pr. B. EL MANSOURI.

This repository is a clean, reproducible rebuild of earlier exploratory work: every number and figure of the
thesis is regenerated by the numbered scripts below, from data aggregated to a fixed 1 km grid inside
Google Earth Engine.

## Layout

```
config.yaml        all paths, period, CRS, grid and parameters (single source of truth)
environment.yml    pinned dependencies
src/tadla/         library code (data, model, irrigation, figures)
scripts/           numbered pipeline steps, each re-runnable on its own
tests/             unit and sanity checks
docs/              cleanup_report.md, old_code_notes.md, results.md
data/, outputs/    generated, git-ignored (outputs/<step>/ per step)
```

## Pipeline

| Step | Script | Status |
|---|---|---|
| 0 | `scripts/00_inventory.py` — read-only inventory of the old material → `docs/cleanup_report.md` | done |
| 1a | `scripts/01a_check_collections.py` — real date coverage of every collection | done |
| 1b | `scripts/01b_build_grid.py` — fixed 1 km grid (EPSG:26191, 800 cells) | done |
| 1 | `scripts/01_export.py` — per cell and month: HLS NDVI, CHIRPS, ERA5-Land actual ET and FAO-56 ET0, soil moisture, T2m, SoilGrids, DEM | 2022 done |
| 1c | `scripts/01c_check_export.py` — sanity checks of one exported year | 2022 done |
| 2 | `scripts/02_build_dataset.py` | to do |
| 3–5 | `03_train.py`, `04_validate.py` (leave-one-year-out), `05_explain.py` (SHAP) | to do |
| 6–8 | `06_predict.py`, `07_irrigation.py`, `08_figures.py` | to do |

## Setup

```bash
conda env create -f environment.yml      # or pip-install the pinned versions in a venv
conda activate tadla
earthengine authenticate
```

Create a `.env` file at the repository root (never committed):

```
GCP_PROJECT=<your Earth Engine / GCP project id>
```

Run a step from the repository root, e.g. `python scripts/00_inventory.py`, and the tests with `pytest`.

## Notes

- The study area is `area.shp` (EPSG:26191, Merchich / Nord Maroc, 701.83 km²), also uploaded as an Earth Engine
  asset; its path is set in `config.yaml`.
- `data/` and `outputs/` are git-ignored. If the repository sits in a OneDrive folder they are still synced to
  the cloud; at 1 km they stay small.
